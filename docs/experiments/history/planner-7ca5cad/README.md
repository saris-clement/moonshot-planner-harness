# Early Phase 2 Planner Research

This directory preserves the complete tracked `docs/experiments` research set from
`Saris-AI/moonshot-planner-poc` commit
`7ca5cadcc64a0b3951ebb24d481343ec8d23f5a1`.

The Markdown studies and compact JSON observations are historical context only.
Their requirements, planner, workflows, model, prompt, budget, and knowledge pins
are not directly comparable with current harness campaigns. Any human or model
interpretation in these files remains distinct from measured run output.

The source study names additional local traces and transcripts that were not
tracked in that Git tree. Their absence is retained as a limitation rather than
silently treated as complete evidence.
